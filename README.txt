# GRAMMAR PROTOCOL — GRAMMAR GAME

A self-contained 16:9 interactive English grammar game.

Features:
- 5 advanced grammar questions
- 25-second timer
- Timer expiry never reveals the answer automatically
- Teacher-controlled REVEAL ANSWER
- Correct-answer popup with success sound
- Wrong-answer popup with error sound
- Score, streak and accuracy
- Interactive answer buttons and visual feedback
- No external libraries or internet required

Open index.html in a modern browser.
